Water-intake-tracker

Personalized Water Intake Tracker

Overview
This project is a simple web-based tool that helps users estimate their daily water intake based on personal factors such as age, weight, height, gender, and health conditions.

Instead of using a generic rule, the tool provides a more personalized recommendation to help users stay properly hydrated.



Features
- Takes user input for:
  - Age
  - Weight
  - Height
  - Gender
  - Health conditions
- Calculates estimated daily water intake
- Adjusts recommendations based on basic conditions
- Provides results in a clear and understandable format
- Lightweight and easy to use



Technologies Used
- HTML
- CSS
- JavaScript
